## Visual evidence and its limit

All four SVG figures are inspected through PNG previews rendered from
their actual rectangle, line, and text elements with the specified Segoe
UI font. Their 67 text boxes fit within the declared view boxes and have
no pairwise overlap in that font measurement. These are static-figure
checks, not browser-rendering or responsive-layout evidence.

The first localhost browser attempt timed out while the restricted shell
also reported a forbidden socket operation. That server was stopped.
A localhost-only server was then started outside the restriction, but
reading the existing browser error tab was rejected by URL policy for
its generated data-URL error page. That browser path was stopped and the
second server was stopped. No alternative browser-control mechanism was
used to retry the rejected path.

Consequently rendered desk interactions, keyboard flow, narrow-viewport
layout, and hosted chapter rendering remain unverified. The pure
JavaScript case checks do not discharge that limitation. Publication and
the draft PR retain this scope; the broad textbook goal remains active.
