# 05. Carry the model with the claim

These two sentences can sound contradictory:

- In the two-answer model, the swap fails only if an admitted report
  has unequal answers.
- In the side-free control, a declared permission restriction can
  exclude the swap without changing the retained labels.

Check the definitions before trying to choose a winner.

The first model defines swap membership by preservation of **all admitted
reports**. It has no additional permission flag. Its theorem follows
from that definition and the declared opposite meanings of preservation
and distinction. You cannot vary a permission flag that its interface
does not contain.

The second model explicitly takes a **permitted family** and filters it
by key preservation. Changing that family is one of its declared
capabilities. Identity-only separation is therefore representable there.
It does not supply a counterexample inside the first model's interface.

Nor do the models price the same thing automatically. One source example
contains exactly one asymmetric report; the control's price counts changed
capability settings. A witness count is not, by itself, a cost-preserving
translation between candidate spaces.

The ledgers preserve an unresolved question: is admission order itself
a kind of container? The oriented-boundary tree proposes an analytic
answer: a reasoned interpretation using its own existence conditions,
rather than a mechanized bridge between the models. That proposal **does not
discharge `SF-OPEN-A`** in the isolated control. A reported synthesis
without its raw runs also supplies no authenticated independent confirmation.

Finally, a static oriented pair is not a clock. The two-answer theorem
adds no internal object recording succession. A word such as “orientation”
does not establish a physical theory of time.
