# Units 11–16: what changed, and what follows?

Try one group at a time before the [separate answers](admission_answers.md).
Each question names its starting model. Carry that model into your answer.

## Admissions and comparisons

1. Start with no tokens. Admit A, supply B, and admit A again. Which tokens
   are stored? Which event would add a second stored token?
2. Instead start with the raw token list [A,B] and use an empty history.
   Does the single-token bound apply? Name its missing starting assumption.
3. Two data have the one-place form marked, both instances admitted, and
   no rule. Add a fresh third datum without an instance. Does the old pair
   remain collapsed? Does the total number of answer profiles stay one?
4. A raw record has two data, a binary form, and the instance linked(2,0).
   Is that instance admissible through the guarded API? Why can increasing
   the raw record's data count to three expose a distinction in the old pair?

## Witnesses and relation models

5. An empty-start history admits A and then B. In Unit 13's theorem choose
   reference token C, absent from that history. Which admission can witness
   the conclusion? Does the conclusion identify a unique second event?
6. In the separate one-point model of Unit 14, a fixed function reads the
   same cell for both inputs. Can its outputs be A and B when A differs
   from B? What changes if both required outputs are A?
7. Take Unit 15's two-element carrier with an empty relation. Are the
   elements unequal? Does the relation contain an arrow between them?
   Does requiring that no element relate to itself create an arrow?
8. Do the results in questions 6–7 automatically admit a form, instance or
   rule to a Genesis ledger? State what would be needed for such a change.

## Requests and evidence

9. A two-datum ledger has no forms and no requests. What are the answers
   to the chosen-pair separation check and Python's all-requests `satisfies`
   check? Explain why they differ.
10. Record request (0,1) in that ledger, then record it again. Does either
    operation add a context? What does `satisfies` return after recording?
11. Starting with that recorded request, admit one unary form and its
    instance on datum 1. Give a separating context and its two answers.
    Is the original request still recorded?
12. Someone treats that successful model repair as a discovery about two
    physical cards. What interpretation and observation records would be
    needed to assess the physical claim? Do not invent a reading.
