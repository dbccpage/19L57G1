# Reasoning lab: what does a claim actually say?

Start with [First steps](../first_steps/README.md). Keep its three cards:
A is blue and round; B is blue and triangular; C is amber and triangular.
No previous logic or mathematical notation is needed here.

We will read a rule, try it on a case, and identify exactly what would
make it fail. A small change in a sentence can change what it claims.
