# Combining systems: changed practice

Use Lessons 30–36 before the separate [answers](COMPOSITES_ANSWERS.md).
All records and procedures below are supplied examples.

1. Join `{p:3,q:8}` with `{r:5}`. Project onto q/r. What happens if
   the second record also names q, with the same value 8?
2. Regroup `((4,9),1)` and identify the original middle value in each
   shape. What extra claim about preparation shares has this proved?
3. Start with A1=4,A2=2,B1=9,B2=6. Compare “add one to A2; relay A2→B1”
   with “relay A2→B1; add one to A2.” Give both final records. What is
   the corresponding relay-without-intervention baseline?
4. Read B1 in the equal-weight list `[0,0,0,1]`, then flip 0/1. Calculate
   both share tables, the total variation distance and the number of
   changed paired readings. Repeat with a constant-zero probe.
5. A rule declares no reads and writes constants to x and y. Does the
   native graph construction add x—y? Does that establish that x's value
   was copied into y, or that the rule has run?
6. Keep the two-edge graph A1—A2 and B1—B2. Values are 3,0,3,8.
   Does swapping parts preserve the graph, the whole record, and equal
   same-probe A1/B1 readouts? Answer each separately. Then compare
   A1=0 and B1=2 with an even/odd probe.
7. A local A update and a readout labelled “B only” pass their declared
   footprint checks, but the callback actually reads A2. Does the label
   establish unchanged answers? What would need to be checked instead?

Explain each answer in words as well as numbers. A correct share table
alone does not answer a question about corresponding rows.
