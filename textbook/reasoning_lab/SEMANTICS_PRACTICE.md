# Meaning and reports: changed practice

Use Lessons 56–61. Explain each answer before consulting the
[answer guide](SEMANTICS_ANSWERS.md).

1. Change the formula to “x is triangular.” Keep x naming A, then B.
   Which answer changes? Which assignment and relation did you use?
2. For the domain containing only B and C, evaluate “every card is
   triangular” and “some card is blue.” Then use an empty domain.
3. A separate truth score is 1/3. Under X301's score operations, find
   its negation and the larger of the score and its negation. Is 1/3
   automatically a measured chance?
4. Starting with B blue, allow only a procedure removing C from blue.
   Is there a witness changing “B is blue”? Now add removal of B.
5. Starting with C absent from blue, use three identical procedures
   inserting C into their views. Give the panel and starting-model
   answers. What would establish that the procedures are independent?
6. Start with B blue, use three unchanged views, and allow removal of B.
   Does the Python guard proceed? Was the starting formula false?
7. Change a receipt's verdict field and retain its old checksum. Then
   recompute the checksum. What does each check establish about the verdict?
8. A model answer and all panel reports say “blue.” No physical trial was
   performed. Name one missing model-to-world comparison and the record
   you would need. Do not invent a reading.
