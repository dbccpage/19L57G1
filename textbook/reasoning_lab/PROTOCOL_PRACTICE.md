# Protocol practice: new readers and update orders

Attempt these before the [separate answers](PROTOCOL_ANSWERS.md).

1. Start at A=2, B=0 with both records 0. Use the copying probe.
   Read A, advance A through 2→0, then read B. Give the two target
   values and both record values. What changes if you read A once more?
2. From the same start, compare reading B before advancing A with reading
   B after it. Then replace read B by read A. Which comparison commutes,
   and which field witnesses a failure in the other one?
3. A=B=2. Read A by copying and B by an always-zero probe. Must their
   records agree? Name the missing hypothesis of the same-probe theorem.
4. A=0 and B=2. Read both with the even/odd probe. Are matching marks
   enough to conclude matching targets? Give a probe that would retain
   this particular distinction.
5. Start with A=2, B=0, M=1, record B=0. Receive, then send. What is B
   now? What is M now? What will a new copying readout of B store?
   Compare with send, receive, read B.
6. Supply a new list of three preparations: (2,2), (0,0), (2,2).
   With copying readouts, compare record-pair agreement before and after
   advancing A only. Give B's shares for values 0 and 2. Do these
   calculations count as three physical observations?

Transfer: a system reports a matching pair of zero marks and a zero
diagnostic counter. Someone concludes both targets are currently equal,
both were recently measured, and no instrument changed either target.
Give distinct counterexamples to those inferences. State what extra
procedure information and empirical evidence would be needed for an
actual device claim. You may change supplied probes or counter prices,
but name every such change.

AuthorityEffect: None. These are supplied exercises. No reader responses
or learning outcomes have been recorded.
