## Supplied family and recipe information

The four square corners are mixtures of indicators in the larger classical
simplex. Their extremality is relative to the family generated by those
four corners. The book proves the zero-coordinate argument for all four
corners using nonnegative integer coefficients at a shared denominator.
For example, V1's outcome-1 zero requires b+c=0 and outcome-3 zero requires
c+d=0, leaving only its own coefficient a. Rational finite mixtures can
be written over a common positive denominator; no Python-to-Lean
translation theorem is asserted.

Different corner weights can yield the same normalized table. All native
effects depend only on that table, so their valuations agree; additional
recipe labels/history are separate data. In a classical indicator family,
weights over the distinct fixed indicators equal the table's corresponding
probabilities. Duplicating a named indicator changes the candidate list.

Bilinearity expands the product of separate mixture weights. It does not
authorize replacing an explicitly coordinated recipe/response selection by
independent selection. The half/half witness retains Yes chances 1/2,
one and zero for the three distinct joint-choice procedures.

## Caller checks and full-branch scope

Native state/effect constructors default omitted outcomes to zero and ignore
mapping keys outside the supplied outcome space. A retained control passes
an extra negative/oversized entry that is ignored. Python bool is accepted
as an int by the native exact-Q conversion. The book's constructors supply
all keys and reject extra labels, booleans and floats through explicit
caller checks before invoking the native operations. Native float inputs
are already refused rather than approximated.

Outcome order is part of native space identity; equal label sets with
different orders do not automatically match for evaluation. The raw marginal
reducer does not require exact product-space identity: an extra zero-weight
outcome can be ignored. The teaching route constructs the exact product
space with the native constructor and retains all four pair entries.

The A effects must sum to the unit effect at each A input. An incomplete
partition is refused, not renormalized. Keeping both branches gives the
unit-effect/marginal identity. Keeping one branch and dividing its joint
contribution by its branch chance computes a separately labelled conditional
chance, supplied by the book calculation. A zero branch chance supplies no
ratio. The native API does not define a state update after measurement,
disturbance, timing, causal influence or communication protocol.
