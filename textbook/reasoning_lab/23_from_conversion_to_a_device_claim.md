# 23. From conversion to a device claim

The desk converts the supplied record 6 U into 3 W. Someone concludes,
“Our physical instrument is now calibrated.”

**Predict:** what observation did that calculation collect?

<details><summary>Check your prediction</summary>

None. It checked an exact calculation under given standard sizes.
It did not read an instrument, establish a standard or test the
association between an object and its recorded number.

</details>

To use the model for a device, specify a **correspondence**: which
actual objects, procedures and readouts the model’s records describe.
State the reference standard and how its size is established. State
the conditions under which the same conversion is expected to apply.
Those application premises need their own evidence.

### A record that could reveal a problem

A single agreement does not establish the rule at every length or
under every condition. Check more than one reference point and retain
repeats, disagreement and uncertainty. A common error can preserve a
ratio while changing both readings, as the previous example showed.
If zero marks do not align, a pure multiplication rule may be unsuitable.
No new model for that offset is supplied by ignoring it.

**Change one thing:** both readings drift together so their ratio stays
fixed. Which additional record would help reveal the shared change?

<details><summary>Check the changed example</summary>

Retain separate comparisons against a stated reference, with the
procedure and conditions. Rechecking only the same ratio may miss it.
This names a useful check; no such physical results have been collected here.

</details>
