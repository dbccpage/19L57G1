# Process practice: change the example

Use paper if you prefer. Explain the input available to each function.
Attempt these before opening the [answers](CHANNELS_ANSWERS.md).

1. A new channel has rows [2/3, 1/3] for input 0 and [1/4, 3/4]
   for input 1. The input chance of 0 is 3/5. Find the output chance of 0.
2. Compare Flip-then-Reset-to-0 with Reset-to-0-then-Flip on both inputs.
   Does associativity make the two orders equal?
3. Store 0 for A and B, and 1 for C. Flip only the stored answer.
   Which of the pairs A/B and A/C remains distinguishable?
4. Reset the first part of (original, original), retaining the second.
   Write the final records for original 0 and 1 and a recovery rule.
5. Keep and Flip give the same output chances on balanced input.
   Are they equal channel tables? Give a changed preparation that tests this.
6. A proposed row is [1/4, 1/4]. Is it valid here? If supplied as
   weights instead, what extra operation and changed row would be needed?
7. Execute Flip, then the one-quarter-flip box, then Reset-to-0.
   Do different placements of calculation brackets change its final rows?
   Does that authorize swapping arbitrary processes?
