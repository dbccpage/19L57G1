# 11. Try one physical check

[Previous](10_repeats_uncertainty_and_scope.md) · [Reasoning lab](README.md)

This optional activity uses paper and a pencil. It produces observations
only if you actually perform it. The book's fictional logs are not your
results. You can study the reasoning without collecting any readings.

## Before looking at the results

1. Label four paper cards K, L, M and N; mark one answer box and the front
   of each. Vary dots and folds without requiring them to satisfy the
   proposed dot-implies-crease rule. Note how you prepared the cards.
2. Write the claim and its exact domain: these four cards, P1, front-desk.
   Decide what lighting and viewing conditions you will use.
3. Write P1's two inspection questions from [Lesson 08](08_from_a_model_to_a_trial.md).
   Fix the Y/N/? legend. Leave uncertain cases as ?.
4. Write a prediction for each card before its recorded inspection.

Preparing examples yourself can demonstrate a counterexample or a
recording difficulty. It does not establish a regularity for arbitrary
cards, devices, or materials.

## Record what you actually did

Use a fresh row for each trial. Add a timestamp or trial number and
enough notes to recover the card, procedure and conditions.

| Trial | Card | Protocol | Conditions | Raw dot | Raw crease | Notes |
|---|---|---|---|---|---|---|
| | | | | | | |

Do not fill blanks with the book's values. Keep predictions separate
from raw readings. If you discover an error, preserve the original and
add the correction and its reason. A repeat is another row.

## Interpret with limits

- Name a counterexample, a compatible row, or an unresolved row and explain why.
- If a result disagrees with the proposed rule, list the application
  assumptions that need checking. Do not claim that the report identifies
  a unique cause.
- Explain what the next observation would test, using a procedure fixed
  before seeing that observation.
- State what these trials leave unmeasured and which wider claim they
  do not establish.

If you did not perform the activity, write **not performed**. That is
more informative than treating an imagined outcome as a measurement.
