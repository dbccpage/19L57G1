# Practice on a different list

[Reasoning lab](README.md) · [Answers, after your attempt](ANSWERS.md)

These are supplied records about three packets, not physical measurements.

| Packet | red? | sealed? | numbered? |
|---|---|---|---|
| K | Yes | Yes | No |
| L | No | Yes | Yes |
| M | No | No | Yes |

For each answer, name the domain and give a reason or a witnessing row.

1. Does “if red, then sealed” hold on K, L, M? Does its reverse hold?
2. Does “red if and only if sealed” hold? Which additional direction
   must pass beyond question 1's first direction?
3. Does numbered agree with not-red on every row? Would this establish
   the same rule for every unlisted packet?
4. Keep only the sealed answer. Can one function recover red on the
   whole list? Give a blocking pair or a recovering rule.
5. Restrict the domain to K and M. Can red now be recovered from sealed?
   Specify the output for each kept input that occurs.
6. Compare “some listed packet is red” and “every listed packet is red.”
   What changes if the selected domain is empty?
7. Make only red and sealed questions available. Check both demands:
   each different-packet pair has some separating question; one available
   question separates every different-packet pair. List the witnesses or
   failure for each claim.
8. Remove every available question while keeping only one packet. Are
   there any different-packet pairs? Does that supply an available
   question as a common witness?
9. A theorem says that a correctly recovering function makes equal kept
   answers give equal requested answers. If no recovery function has yet
   been found, have we proved that the requested answers differ?
10. Design a new row that would refute “if red, then sealed.” Then
    describe what would be required to test a similar claim on real packets.
