# Calibration practice: change the records

Read Lessons 18–23 first. Work on these changed values before opening
the [answers](CALIBRATION_ANSWERS.md). The standards below are supplied
model assumptions, not measured reference objects.

1. P spans three model steps; R spans six. A strip is recorded as 5 P.
   Predict its record in R. Give the scale, the new number and both
   reconstructed magnitudes. What changes if the new standard spans
   only one step?
2. Compare 5 P with 5 R using the same-kind ratio. Is the result one
   because the numbers match? Convert to a common reference and state
   which magnitude divides which.
3. In P units, compare pairs (2,4) and (6,12). What ratio does each give?
   Do equal ratios establish equal first magnitudes? Now double only
   the second entry of the first pair.
4. A positive scale of 1/2 is supplied while changing from P to R.
   What number would the unchecked division formula return for 5 P?
   Why is that not a valid conversion with these standard sizes? Give
   one additional malformed record that the teaching checks should refuse.
5. Distinguish zero length divided by a positive length, division by
   zero length, and length divided by duration under P201’s particular
   same-kind operation. Does the last refusal prove that no rate can
   ever be defined? What extra definition is missing?
6. A team says a ratio remained unchanged after relabelling both
   records, so its device is calibrated. Construct a changed counterexample
   within the supplied model and name an independent reference comparison
   that could test the proposed physical correspondence. Does your
   invented example itself provide a physical observation?
