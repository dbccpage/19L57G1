# Practice: new items and waiting work

[Growth lab](README.md) · [Answers after your attempt](ANSWERS.md)

Use new item labels P, Q, R, S. The commitment requires all distinct pairs
apart. One view asks “is the item P or R?” A second view, initially absent,
would ask “is the item Q or R?”

1. Hold P, Q, R with the first view only. List the unresolved demands.
2. Admit S without changing that view. List the new demands separately
   from the old demands. Did growth resolve any old pair?
3. Start again with P, Q, R and both views. Admit S. Is there a demand?
   Explain why this need not match the earlier 4/3 reopening exhibit.
4. With no views, how many demands does fresh S add to the three held items?
   Which hypotheses justify that count?
5. Change the commitment to “no pairs required.” What now follows from
   an empty demand list about whether the views distinguish P and R?

For a separate accounting exercise, supply round arrival counts
0, 2, 2, 0, 0. Begin empty, discharge up to one oldest entry per round,
and save no unused capacity.

6. Write every backlog. Does the run end clear? Was it clear every round?
7. Find the least end-clearing budget. Compare it with the peak arrival
   count. Explain the difference without changing the discharge rule.
8. If the experiment says “two removed,” what additional evidence would
   establish that an actual observation repair occurred?
9. Someone calls this schedule “the source's frozen prediction.” Explain
   why that attribution is unsupported; this schedule was supplied here.

AuthorityEffect: None. These items, views, and arrival counts are new
teaching inputs. The accounting exercise is not the represented-view model.
