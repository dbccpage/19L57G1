# 05. Recheck a shortcut when the task changes

A search shortcut can be correct for one task and wrong for another.
The separation search has a theorem allowing it to discard replies
containing uniform rules when looking for minimum separating replies.
That theorem has a particular goal and hypotheses.

Now reset the arrow record to B → B and B → C, release the old
promises, and ask to **match A and B**. A uniform rule for the arrow
form makes every arrow question answer yes for every card. The
profiles match, at a cost of one item. C matches them too; no retained
promise forbids that in this setting.

What if we discard every reply containing a uniform rule, reusing
the separation shortcut? The finite check then finds no valid reply
within two items. It has thrown away the only one-item answer.

This is not a defect in the separation theorem. Matching profiles
has a different success condition. The rule that was dispensable for
separation is useful for removing a difference in these examples.

When you reuse a shortcut, write down three things:

1. What counts as success now?
2. Which promises must the reply preserve?
3. Does the proof of the shortcut cover that exact task?

The research uses the unpruned addition enumeration for matching.
Our recorded bounded search does the same. The comparison is a
finite example of why the opposite goal needs a fresh check; it is
not a general characterization of all useful search shortcuts.
