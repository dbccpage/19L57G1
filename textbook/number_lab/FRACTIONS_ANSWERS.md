# Fraction practice answers

Attempt the [practice](FRACTIONS_PRACTICE.md) first.

1. Yes: multiplying both parts of 3/4 by two gives 6/8. No: one quarter
   is two eighths, so 1/4 and 1/8 differ for the same whole.
2. `1/3 + 1/4 = 4/12 + 3/12 = 7/12`. The denominator keeps track of
   the common piece size. The calculation `(1+1)/(3+4) = 2/7` is not
   fraction addition.
3. `2/3 × 9/10 = 18/30 = 3/5` of the sheet.
4. `(3/4) ÷ (1/2) = 3/2` half-sheet units. The unit is smaller than a
   whole sheet. Check: `3/2 × 1/2 = 3/4` sheet.
5. `0 ÷ (1/4) = 0`. Division by the zero value is not supplied, so
   `(1/4) ÷ 0` has no quotient here. A denominator zero does not form
   a fraction, so 3/0 is not admitted either.
6. The first is `3/4 × 2/3 = 1/2`. The second is
   `1/2 + 1/6 = 2/3`. They specify different operation groupings.
