# Number lab: from counts to a combined reading

Two separate numerical records can agree while a combined reading differs.
To understand why, we will build the arithmetic a step at a time: totals,
shares, signed steps, squares, and pairs of coordinates.

Begin after [First steps](../first_steps/README.md), the
[Reasoning lab](../reasoning_lab/README.md), and the
[Map lab](../map_lab/README.md). We introduce each numerical operation
before using it. The numbers and operations are admitted mathematical
tools; this route does not derive them from the opaque mark.

| Lesson | One question |
|---|---|
| [00. Count and multiply](00_count_and_multiply.md) | What does a total count, and what does multiplication repeat? |
| [01. Compare shares](01_compare_shares.md) | Can different totals have the same proportions? |
| [02. Check the zero case](02_check_zero.md) | Why does an empty total need its own rule? |
| [03. Use signed steps](03_signed_steps.md) | How can a number carry a direction? |
| [04. Square before or after adding?](04_square_and_add.md) | Which information does squaring forget? |
| [05. Add two coordinates](05_two_coordinates.md) | How can equal separate weights give readings 4, 2, and 0? |
| [06. Ask what the weights determine](06_what_weights_determine.md) | Can a lookup recover an answer that varies within one recorded row? |
| [07. Pair positions under reversal](07_pair_positions.md) | How many distinct readings can a reversal-preserving rule give? |
| [08. Test the interpretation](08_test_the_interpretation.md) | What would turn this calculation into a tested claim about reality? |

Pause at the predictions before reading the worked answers. Then try the
changed examples in [practice](PRACTICE.md), with separate
[answers](ANSWERS.md). Five figures show the actual recorded calculations.

the separately admitted research model are not interchangeable definitions.
