## Corrections to broad readings

- A disjoint dictionary merge preserves named entries; generic Lean product
  regrouping uses an explicit associator. Neither establishes statistical
  independence. Python and Lean execution correspondence is not proved.
- Lean's four Nat fields are unbounded. Its local intervention actually
  receives and writes only A fields, so pointwise B preservation is general
  within that definition. Finite Python populations do not bound it.
- Python checks returned write keys, not actual reads or observable labels.
  A retained misleading B-local readout really reads A2. A disposable-state
  mutation bypasses the guard through the shallow frozen dictionary.
- The graph is constructed from declarations, without running updates. It
  is undirected; multi-write constants add an edge even without copying,
  and an undeclared read can hide a real dependency. Graph distance supplies
  no physical length, propagation time or reverse copy procedure.
- Native Lean connectivity results merely evaluate a supplied Boolean
  bridge flag. They are not graph-construction or shortest-path proofs.
- The leaky/mediated Lean divergences are concrete witnesses. Crossing a
  cut need not change every readout's distribution. A binary flip keeps
  balanced shares while changing every paired mark. A constant probe hides
  all such changes. The desk retains both paired marks and exact shares.
- Both relay comparisons use relay-without-intervention as baseline.
  Operation order remains explicit; an available edge is not an executed relay.
- Graph, state and operation symmetry are distinct. The native duplicate
  helper validates neither the graph automorphism nor its relation to the
  observed pair. An identity-map control classifies an unequal pair as
  symmetric; the report does not certify duplicate agreement. Empty symmetric
  populations return rate one but a false satisfaction flag.

These are teaching scope corrections. Research README/ledger wording,
implementations, manifests and receipts remain read-only and unchanged.
