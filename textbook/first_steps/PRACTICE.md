# Practice: use the ideas on a new table

[First steps](README.md) · [Separate worked answers](ANSWERS.md)

Try the questions before opening the answers. Explain each prediction with
a pair of items or an explicit rule, rather than a remembered phrase.

We supply four parcels and a complete table of two test answers:

| Parcel | heavy? | sealed? |
|---|---|---|
| P | Yes | No |
| Q | Yes | No |
| R | No | Yes |
| S | No | No |

These words name supplied test tables in this exercise. They are not
measurements of actual parcels.

1. A recorder keeps only **heavy?**. Which parcels share a recorded
   pattern? Give all its groups.
2. The recorder adds **sealed?** while retaining the old answers. Give
   the new groups. Has every pair become separated? Name a pair and the
   test that witnesses its separation.
3. Rename P to **Oak** while keeping all test tables fixed. Which
   groups change? Name the assumption your answer uses.
4. The recorder keeps both questions, then deletes **sealed?**. Give a
   pair whose distinction is lost. This is a counterexample to which
   broader claim about changes to an observation system?
5. With both answers recorded, someone asks **urgent?**. We supply the
   urgent answers P: Yes, Q: No, R: Yes, S: Yes. Can that answer always
   be recovered from the recorded pattern? Exhibit a blocking pair or
   a lookup rule covering every recorded group.
6. A second requested answer is **ordinary?**, with P: Yes, Q: Yes,
   R: No, S: Yes. Can it be recovered from both recorded answers? Write
   one rule for each group. Does that establish whether any actual
   parcel in the world is ordinary?

When you finish, write one question you could ask a real measuring device
to investigate whether it has lost information needed for another task.
State what would have to be measured to answer your question.
