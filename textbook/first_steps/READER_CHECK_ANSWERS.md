# Reader-check answers and marking guide

[Questions](READER_CHECK.md) · [First steps](README.md)

These are proposed assessment criteria. No pilot results are recorded here.
Use an incorrect answer to locate a specific failed explanation and revise
that explanation. Do not treat a score as a verdict about the reader.

| Task | Expected result | Explanation needed |
|---|---|---|
| 1 | No answer changes | The machine reads the supplied questions, with fixed tables, rather than display labels |
| 2 | `{J, K, M}` and `{L}` | Equal recorded answers group distinct admitted list entries; J and K remain separate entries |
| 3 | **lamp on?** separates J (Yes) from K (No); J and M remain together | Name the actual witness and answers, then identify an agreeing pair |
| 4 | Old questions and answers must remain unchanged; replacing lamp-only by clicks-only loses J/K | State both the hypothesis and the counterexample |
| 5 | Recovery fails; J/K or K/M blocks it | The pair shares clicks = Yes but needs different lamp answers |

Score each task from zero to two:

- **2:** correct result with the stated reason or an equivalent clear explanation.
- **1:** correct result with a missing or unclear reason, or sound reasoning with a minor transcription error.
- **0:** incorrect result or reasoning that uses information unavailable to the declared machine.

A provisional development target is at least four tasks earning 2, with
a correct transfer explanation. It is a target to test and revise, not a
validated educational standard. Preserve the responses; the total alone
does not show which intuition was learned.

For the transfer question, a sufficient answer supplies one explicit test
with different answers on the selected items, then says how the machine
receives or records that test. A name-reading test could do so only after
it is explicitly introduced. A new label by itself changes no available
test under the stated machine rules.

For a delayed check, use a different supplied table with different item
labels and ask for a witness, a lost distinction after replacement, and
a blocking pair. Record the time interval. Do not reuse these exact rows
and infer transfer from recall of their answer key.
