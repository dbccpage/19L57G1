# 03. Keep a question or replace it?

[Previous: answer patterns](02_answer_patterns.md) · [First steps](README.md) · [Next: recover an answer](04_recover_an_answer.md)

## Predict two different changes

Start with only **blue?**. A and B share an answer; C is separate.

1. Keep **blue?** and add **triangle?**.
2. Remove **blue?** and use **triangle?** instead.

Will these changes give the same groups? Work out the answers before
reading on.

## Adding keeps the old answers

With both questions, the patterns are:

- A: Yes, No.
- B: Yes, Yes.
- C: No, Yes.

All three cards are separated. The old **blue?** answer is still present.
Whenever that answer distinguished two cards, it still does.

Splitting an old group while retaining its old distinctions is called a
**refinement**. Here adding a question refines the grouping because every
old question and every old answer is retained unchanged.

## Replacing can lose an old distinction

With only **triangle?**, A answers no while B and C both answer yes.
So A becomes separate, but B and C now share an answer.

The machine has gained a way to separate A and B and lost its way to
separate B and C. Replacement is not the same operation as addition.

## State the condition that made the first conclusion work

A **hypothesis** is a condition a conclusion uses. Our hypothesis was:
keep every old question with its old answers and append a new question.
Under that condition, an old witness is still available.

If we change an old answer or delete an old question, that reason no
longer applies. “Any change improves observation” would be an overclaim.
The replacement example gives a **counterexample**: a case in which that
broader claim fails.
