# Cost practice: change the route and the question

Attempt these before the [separate answers](COST_ANSWERS.md).

1. Start live at budget 2 with license on. Write budgets 0, 2, 2.
   Give each signed budget change, each state-change count, the totals,
   and the number of attempted events. Is this a full-state loop?
2. Add 7 to the budget potential at every state. What changes in the
   step costs? Explain the cancellation without appealing to the desk.
3. In a separately supplied three-point graph, assign values A=2,
   B=5, C=1. Define every directed edge cost as after-value minus
   before-value. Compare A→B→C with A→C, then total A→B→C→A.
   These graph edges are not native passage events unless an adapter is
   separately supplied.
4. Change those forward edge costs to AB=1, BC=1, AC=−1, with reverse
   edges defined to negate the forward cost. Can any integer potential
   explain all six directed edges? Give a decisive witness or a verified
   potential, rather than checking only one guessed assignment.
5. Compare halt then license-off with license-off then halt, first from
   a live initial state, then from a halted initial state. List the ends
   and the state-change totals. In which comparison does the closed-cost
   premise apply?
6. Supply a new cost counting only steps that change license. Its
   budget loop has cost 0. Does that prove it exact? Check license-off
   followed by license-on from the live initial state with license on.

Transfer: a colleague checks many commuting squares and concludes that
every pair of histories with equal endpoints has equal cost. Explain the
missing step, using the empty history and the budget return loop. Name
one stronger requirement that would justify an endpoint-only cost claim,
and say what must be checked before interpreting the cost physically.
