# Units 08–10: tests, witnesses and search

Try these after Unit 10, before the [separate answers](context_answers.md).
Use the declared tests and say which model each answer concerns.

1. With data 0 and 1, one unary form marked, only `marked(0)` admitted
   and no rule, give the two answers and the two profiles. Which context
   witnesses separation? Does finding it change either index?
2. A separate model has two data and one three-place form. Plug 1 into
   the raw context `(_,0,_)`. Give all three resulting arguments. Which
   positions were supplied in advance, and which were holes?
3. With two data and one binary form, compare `(_,2)`, `(0,1)` and
   `(_,_)`. Which are well-formed contexts? Would a uniform rule make an
   invalid context become well formed?
4. Change Unit 09's binary example so that only `linked(1,0)` is admitted.
   Read the five contexts in the displayed order. Where is the first
   witness? What would checking only the first row establish?
5. Compare a no-form ledger, a unary-form-only ledger, and a unary ledger
   with a uniform rule but no instances. Are the profiles empty or full?
   Are two admitted data collapsed in each?
6. Start with only `marked(1)` admitted. Add the uniform rule for marked.
   Which derivability answers change, and what happens to separation?
7. A ledger has two unary forms. Form 0 has neither instances nor a rule;
   form 1 has only the instance on datum 1. A scanner checks only form 0
   and reports “no witness.” Is its list complete? Give a missed witness.
8. A recorded-instance lookup returns No. What would connect that model
   result to a physical claim that a card is unmarked? Name the additional
   observation procedure or assumption needed; do not invent a reading.

AuthorityEffect: None. Seven computational questions and one evidence question.
