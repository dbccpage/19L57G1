# Unit 70: Can a Pair Be Chosen in a Way Every Relabelling Respects?

**Claim.** A selector required to respect every permitted relabeling may be blocked by symmetry. The obstruction depends on the stated action and selection requirements.

## First pass

Imagine two points exchanged by a swap. A choice that treats both presentations alike must still choose after the swap.

If the chosen point must also be unchanged by the swap, neither point works: each is moved to the other.

Separate the carrier, the allowed relabelings, and the required kind of choice before reading the general obstruction.

## Detailed claim and formal anchors

`CL-PN-NATURAL-SELECTION`, `CL-PN-HETEROGENEOUS-TRANSPORT` (`FROZEN` / `VERIFIED_FINITE` / `OPEN`) — `lean4/Derivation/PresentationNaturality.lean`
**Prerequisites**: Unit 44 (`DiffInterface`: `DiffObs`, `ZeroRel`, `kernelObs`), Unit 69 (`ContactKernel`: `NonZeroPair`, `boolEqObs`, `swapObs`, `no_equivariant_pair_valued_map`)

## Question

Unit 69 established that for a fixed observer `O`, same-data kernels (`SameDataKernel O`) correspond one-to-one with admissible pairs (`NonZeroPair O`), and that `no_equivariant_pair_valued_map` rules out a total map `DiffObs Bool Bool → Bool × Bool` commuting with `swapObs`. How do we formulate the transport of admissible pairs across presentation isomorphisms between observers (potentially over different carriers and residual types), when does a declared family of presentations and relabellings admit a natural section of the admissible-pair bundle, and how does this section-level obstruction relate to the sealed selector theorem?

## What we already possess

- From Unit 44 (`DiffInterface`): `DiffObs X R`, `ZeroRel O x y := O.Zero (O.delta x y)`, and `kernelObs (view : X → V) : DiffObs X (V × V)` with `Zero p := (p.1 = p.2)`.
- From Unit 69 (`ContactKernel`):
  - `NonZeroPair O := { p : X × X // ¬ ZeroRel O p.1 p.2 }`,
  - `boolEqObs : DiffObs Bool Bool` (`delta := xor`, `Zero := (· = false)`),
  - `swapObs (O : DiffObs Bool R) : DiffObs Bool R` (`delta x y := O.delta (!x) (!y)`),
  - `no_equivariant_pair_valued_map : ¬ ∃ sel : DiffObs Bool Bool → Bool × Bool, ∀ O, sel (swapObs O) = (!(sel O).1, !(sel O).2)`.

## New concept

`PresentationNaturality` (`lean4/Derivation/PresentationNaturality.lean`) constructs the transport machinery for admissible pairs and tests natural selection over declared families:

- **Explicit bijections (`Bij A B`)**:
  - `fwd : A → B`, `bwd : B → A`, `fwd_bwd : ∀ b, fwd (bwd b) = b`, and `bwd_fwd : ∀ a, bwd (fwd a) = a`. Because both inverses are carried as data, no choice principle is needed to invert a bijection.
  - Operations: `Bij.rfl' A`, `Bij.symm f`, `Bij.trans f g`, and `Bij.fwd_injective`.
- **Presentation isomorphisms (`PresIso O O'`) and pair transport**:
  - For `O : DiffObs X R` and `O' : DiffObs X' R'`, `PresIso O O'` carries `car : Bij X X'`, `res : Bij R R'`, `delta_transport : ∀ x y, res.fwd (O.delta x y) = O'.delta (car.fwd x) (car.fwd y)`, and `zero_transport : ∀ r, O.Zero r ↔ O'.Zero (res.fwd r)`.
  - `zeroRel_transport F x y : ZeroRel O x y ↔ ZeroRel O' (F.car.fwd x) (F.car.fwd y)`.
  - Operations and component laws: `PresIso.refl`, `PresIso.symm`, `PresIso.trans`, `refl_car`, `trans_car`, `symm_car_left`, `symm_car_right`, `symm_symm_car`.
  - `PresIso.mapPair F : NonZeroPair O → NonZeroPair O'` maps `⟨(x, y), hw⟩` to `⟨(F.car.fwd x, F.car.fwd y), ...⟩` using `zeroRel_transport`, with coherence laws `mapPair_refl`, `mapPair_trans`, `mapPair_symm_left`, and `mapPair_symm_right`, plus `viable_transport` (`Nonempty (NonZeroPair O) → Nonempty (NonZeroPair O')`). (`Viable X R` packages an observer with `Nonempty (NonZeroPair obs)` and is unused by later theorems.)
- **Homogeneous and heterogeneous declared families, sections, and naturality**:
  - `Family X R` declares `Obj : Type`, `obs : Obj → DiffObs X R` (fixed `X, R`), `Arr : Type`, `src tgt : Arr → Obj`, and `iso : (f : Arr) → PresIso (obs (src f)) (obs (tgt f))`. A section is `Sec D := ∀ a : D.Obj, NonZeroPair (D.obs a)`, and `IsNatural D s := ∀ f : D.Arr, (D.iso f).mapPair (s (D.src f)) = s (D.tgt f)`. `autoFamily O F` is the one-object (`Unit`), one-arrow (`Unit`) family generated by `F : PresIso O O`.
  - `HFamily` lets the carrier `car : Obj → Type` and residual type `res : Obj → Type` vary with `a : Obj`, indexing declared arrows by `Hom : Obj → Obj → Type` with `iso : (a b : Obj) → Hom a b → PresIso (obs a) (obs b)`. Its sections and naturality predicate are `HSec D` and `HIsNatural D s`. `hAutoFamily O F` is the one-object `HFamily`, bridged to `autoFamily O F` by `hAuto_iff_auto`.
- **The fixed-point obstruction and its two boundary fixtures**:
  - `no_natural_section_of_fixed_point_free`: if `∀ p : NonZeroPair O, F.mapPair p ≠ p`, then `¬ ∃ s : Sec (autoFamily O F), IsNatural (autoFamily O F) s`. Conversely, `fixed_pair_of_natural_section` extracts a fixed pair `F.mapPair (s ()) = s ()` from any natural section.
  - `no_natural_section_of_endo`: in any `HFamily D`, if some object `a : D.Obj` has a declared endomorphism `h : D.Hom a a` fixing no admissible pair of `D.obs a`, then `¬ ∃ s : HSec D, HIsNatural D s`.
  - **Negative boundary (`boolEqObs` with `negIso`)**: `notBij` (`not` on `Bool`) and `Bij.rfl' Bool` form `negIso : PresIso boolEqObs boolEqObs`, which fixes no admissible pair (`negIso_fixed_point_free`, `no_natural_section_boolEq`), while `boolEqRawSection` exhibits a raw section (`selection_is_possible_naturality_is_not`).
  - **Positive boundary (`card4Obs` with `twIso`)**: on `Card4 = {e1, e2, e3, e4}`, `card4Obs := kernelObs id` has 12 admissible pairs; `tw` swaps `e1 ↔ e2` and fixes `e3, e4`, so `twIso` fixes `card4Pair = ⟨(e3, e4), ...⟩` (`card4_natural_section`, `card4_has_natural_section`, `naturality_separates_presentations`).
  - **Heterogeneous two-object separation (`twoFamilyNeg` vs. `twoFamilyPos`)**: over `Two = {bool, four}` with `twoObs .bool = boolEqObs`, `twoObs .four = card4Obs`, and `twoHom` equal to `Unit` on the diagonal and `Empty` off the diagonal, declaring `negIso` at `.bool` and `twIso` at `.four` yields no natural section (`twoFamilyNeg_no_section`), whereas replacing the `.bool` arrow by `PresIso.refl boolEqObs` admits the natural section `twoSectionPos` (`twoFamilyPos_natural`, `twoFamilyPos_has_section`, `heterogeneous_naturality_separates`).
  - **Co-statement with the sealed selector theorem**: `bool_obstruction_and_sealed_selector` states `negIso_fixed_point_free`, `no_natural_section_boolEq`, and `ContactKernel.no_equivariant_pair_valued_map` as a conjunction without deriving either from the other.

## Plain-language interpretation

Suppose an observer `O` has several admissible (non-zero) pairs, and we also have a symmetry or relabelling `F : PresIso O O` of that observer's presentation.

1. **Selecting a pair vs. selecting a pair naturally**: Picking an admissible pair is always possible whenever `NonZeroPair O` is inhabited — for `boolEqObs`, we can pick `(false, true)` (`boolEqRawSection`). Picking a pair *naturally* with respect to `F` means that applying the relabelling `F.mapPair` to our chosen pair gives back the exact same pair.
2. **Why the one-object obstruction is near-definitional, and why the positive fixture matters**: Over a one-object family `autoFamily O F`, a section `s` only picks one pair `p = s ()`, and naturality `IsNatural (autoFamily O F) s` says `F.mapPair p = p`. Therefore, as `Textbook.U70.natural_section_iff_fixed_pair` checks, a natural section over `autoFamily O F` exists if and only if `F.mapPair` has a fixed admissible pair. What gives the setup mathematical content is the transport machinery (`PresIso`, `zeroRel_transport`, `mapPair`) together with the two finite fixtures: on `Bool` with negation (`negIso`), neither `(false, true)` nor `(true, false)` is fixed (`no_natural_section_boolEq`), whereas on `Card4` with the transposition `e1 ↔ e2` (`twIso`), the pair `(e3, e4)` is fixed (`card4_has_natural_section`). Thus having multiple admissible pairs does not by itself block natural selection; what decides the question is whether the declared relabelling fixes at least one admissible pair.
3. **Why `no_equivariant_pair_valued_map` is co-stated, not derived**: `ContactKernel.no_equivariant_pair_valued_map` quantifies over total functions `sel : DiffObs Bool Bool → Bool × Bool` on the type of all Boolean observers (including collapsed ones) under `swapObs`, whereas `no_natural_section_boolEq` quantifies over dependent sections `Sec (autoFamily boolEqObs negIso)` taking values in the subtype `NonZeroPair boolEqObs`. Rather than claiming one implies the other, `bool_obstruction_and_sealed_selector` states them side by side and leaves any formal reduction `OPEN`.

## Pseudocode

```text
STRUCTURE Bij(A, B):
    fwd : A -> B,  bwd : B -> A
    fwd_bwd : forall b, fwd(bwd(b)) == b
    bwd_fwd : forall a, bwd(fwd(a)) == a

STRUCTURE PresIso(O : DiffObs(X, R), O' : DiffObs(X', R')):
    car : Bij(X, X'),  res : Bij(R, R')
    delta_transport : forall x y, res.fwd(O.delta(x, y)) == O'.delta(car.fwd(x), car.fwd(y))
    zero_transport  : forall r, O.Zero(r) <-> O'.Zero(res.fwd(r))

FUNCTION mapPair(F : PresIso(O, O'))(p : NonZeroPair(O)) -> NonZeroPair(O'):
    RETURN (F.car.fwd(p.1), F.car.fwd(p.2))   # admissible by zeroRel_transport

THEOREM no_natural_section_of_endo(D : HFamily, a : D.Obj, h : D.Hom(a, a)):
    IF forall p in NonZeroPair(D.obs(a)), D.iso(a, a, h).mapPair(p) != p:
        RETURN NOT EXISTS s : HSec(D), HIsNatural(D, s)
```

```python
@dataclass(frozen=True)
class PresIso(Generic[X, R, Xp, Rp]):
    src: DiffObsModel[X, R]
    tgt: DiffObsModel[Xp, Rp]
    car: Bij[X, Xp]
    res: Bij[R, Rp]

    def check_laws(self) -> bool:
        if not (self.car.check_laws() and self.res.check_laws()):
            return False
        delta_ok = all(
            self.res.fwd(self.src.delta(x, y))
            == self.tgt.delta(self.car.fwd(x), self.car.fwd(y))
            for x in self.src.carrier
            for y in self.src.carrier
        )
        zero_ok = all(
            self.src.zero(r) == self.tgt.zero(self.res.fwd(r))
            for r in self.src.residuals
        )
        return delta_ok and zero_ok

    def map_pair(self, p: tuple[X, X]) -> tuple[Xp, Rp]:
        return (self.car.fwd(p[0]), self.car.fwd(p[1]))
```

## Line-by-line Python explanation

- `Bij.check_laws()`: checks both round trips `fwd(bwd(b)) == b` on `codomain` and `bwd(fwd(a)) == a` on `domain`.
- `PresIso.check_laws()`: verifies `car.check_laws()`, `res.check_laws()`, `delta_transport` on all pairs `(x, y)` in `src.carrier`, and `zero_transport` on all `r` in `src.residuals`.
- `PresIso.map_pair(p)`: transports an admissible pair `(p[0], p[1])` along the carrier bijection `car.fwd`.
- In `u70_presentation_naturality.py`:
  - On `boolEqObs` with `negIso`, `nonzero_pairs()` returns `[(False, True), (True, False)]` (2 raw sections), and `neg_iso.map_pair` fixes `0` pairs.
  - On `card4Obs` with `twIso`, `nonzero_pairs()` returns all $4 \times 3 = 12$ off-diagonal pairs of `("e1", "e2", "e3", "e4")`, of which `tw_iso.map_pair` fixes `[("e3", "e4"), ("e4", "e3")]`, and checks `mapPair_refl`, `mapPair_trans`, `mapPair_symm_left`, and `mapPair_symm_right` on all 12 pairs.
  - Across all $4! = 24$ carrier permutations of `Card4`, every permutation defines a valid `PresIso card4Obs card4Obs`; the number of fixed admissible pairs is $k(k - 1)$ where $k$ is the number of fixed points of the permutation, so $7$ permutations (the identity with $k = 4$ and the $6$ transpositions with $k = 2$) admit natural sections while $17$ permutations ($8$ three-cycles with $k = 1$ and $9$ derangements with $k = 0$) admit none.
  - On `twoFamilyNeg` and `twoFamilyPos`, there are $2 \times 12 = 24$ raw dependent sections `HSec`; `0` are natural for `twoFamilyNeg` and $2 \times 2 = 4$ are natural for `twoFamilyPos`.

```lean
structure Bij (A B : Type) where
  fwd : A → B
  bwd : B → A
  fwd_bwd : ∀ b, fwd (bwd b) = b
  bwd_fwd : ∀ a, bwd (fwd a) = a

theorem Bij.fwd_injective (f : Bij A B) {a a' : A} (h : f.fwd a = f.fwd a') :
    a = a' := by
  have := congrArg f.bwd h
  rwa [f.bwd_fwd, f.bwd_fwd] at this

structure PresIso (O : DiffObs X R) (O' : DiffObs X' R') where
  car : Bij X X'
  res : Bij R R'
  delta_transport : ∀ x y, res.fwd (O.delta x y) = O'.delta (car.fwd x) (car.fwd y)
  zero_transport : ∀ r, O.Zero r ↔ O'.Zero (res.fwd r)

theorem zeroRel_transport {O : DiffObs X R} {O' : DiffObs X' R'}
    (F : PresIso O O') (x y : X) :
    ZeroRel O x y ↔ ZeroRel O' (F.car.fwd x) (F.car.fwd y) := by
  show O.Zero (O.delta x y) ↔ O'.Zero (O'.delta (F.car.fwd x) (F.car.fwd y))
  rw [← F.delta_transport x y]
  exact F.zero_transport (O.delta x y)

def PresIso.mapPair {O : DiffObs X R} {O' : DiffObs X' R'}
    (F : PresIso O O') (p : NonZeroPair O) : NonZeroPair O' :=
  ⟨(F.car.fwd p.val.1, F.car.fwd p.val.2), fun h =>
    p.property ((zeroRel_transport F p.val.1 p.val.2).mpr h)⟩

theorem no_natural_section_of_fixed_point_free
    (O : DiffObs X R) (F : PresIso O O)
    (hfree : ∀ p : NonZeroPair O, F.mapPair p ≠ p) :
    ¬ ∃ s : Sec (autoFamily O F), IsNatural (autoFamily O F) s := by
  rintro ⟨s, hs⟩
  exact hfree (s ()) (hs ())

theorem selection_is_possible_naturality_is_not :
    Nonempty (Sec (autoFamily boolEqObs negIso)) ∧
    ¬ ∃ s : Sec (autoFamily boolEqObs negIso),
        IsNatural (autoFamily boolEqObs negIso) s :=
  ⟨⟨boolEqRawSection⟩, no_natural_section_boolEq⟩
```

## Line-by-line Lean explanation

- `Bij.fwd_injective`: applies `congrArg f.bwd` to `f.fwd a = f.fwd a'` and rewrites both sides with `f.bwd_fwd`.
- `zeroRel_transport`: unfolds `ZeroRel` on both sides, rewrites `O'.delta (F.car.fwd x) (F.car.fwd y)` to `F.res.fwd (O.delta x y)` via `← F.delta_transport x y`, and applies `F.zero_transport`.
- `PresIso.mapPair`: maps `p.val` to `(F.car.fwd p.val.1, F.car.fwd p.val.2)`; if the image pair were zero-related in `O'`, `(zeroRel_transport F p.val.1 p.val.2).mpr` would make `p` zero-related in `O`, contradicting `p.property`.
- `no_natural_section_of_fixed_point_free`: for `s : Sec (autoFamily O F)`, `hs : IsNatural (autoFamily O F) s` applied to `()` gives `F.mapPair (s ()) = s ()`, contradicting `hfree (s ())`.
- `negIso_fixed_point_free`: projects the first component of `negIso.mapPair p = p` to get `!p.val.1 = p.val.1`, which `decide` refutes on `Bool`.
- `twIso` and `card4_natural_section`: `twBij.fwd_injective` supplies the backward direction of `zero_transport`; at `card4Pair = ⟨(.e3, .e4), ...⟩`, `tw .e3 = .e3` and `tw .e4 = .e4`, so `Subtype.ext; rfl` establishes `twIso.mapPair card4Pair = card4Pair`.
- `no_natural_section_of_endo`: evaluates a putative natural section `s : HSec D` at the single object `a` and endomorphism `h : D.Hom a a`, obtaining `(D.iso a a h).mapPair (s a) = s a` and contradicting `hfree (s a)`.
- Book `natural_section_iff_fixed_pair` and `twoHom_cross_empty`: show that over `autoFamily O F`, natural sections and fixed admissible pairs are equivalent, and that `twoFamilyNeg`/`twoFamilyPos` have `Empty` cross-object hom types.

## What has been proved

- **Bijection and presentation-isomorphism calculus**: `Bij.fwd_injective`, `zeroRel_transport`, `refl_car`, `trans_car`, `symm_car_left`, `symm_car_right`, `symm_symm_car`, `viable_transport`, `mapPair_refl`, `mapPair_trans`, `mapPair_symm_left`, and `mapPair_symm_right`.
- **Section-level fixed-point obstructions**: `no_natural_section_of_fixed_point_free`, `fixed_pair_of_natural_section`, and `no_natural_section_of_endo` (plus Book `natural_section_iff_fixed_pair`).
- **Two-element and four-element boundary fixtures**: `negIso_fixed_point_free`, `no_natural_section_boolEq`, `selection_is_possible_naturality_is_not`, `tw_involutive`, `card4_natural_section`, `card4_has_natural_section`, and `naturality_separates_presentations`.
- **Heterogeneous two-object separation and co-statement**: `hAuto_iff_auto`, `twIso_fixes_card4Pair`, `twoFamilyNeg_no_section`, `twoFamilyPos_natural`, `twoFamilyPos_has_section`, `heterogeneous_naturality_separates`, and `bool_obstruction_and_sealed_selector`.

## What has not been proved

- **Endomorphisms only, and empty cross-object arrows in the two-object fixtures**: In `no_natural_section_of_endo`, the obstruction uses only a declared endomorphism `h : D.Hom a a` at a single object `a`; arrows between distinct objects play no role in the proof. In `twoFamilyNeg` and `twoFamilyPos`, `twoHom .bool .four = Empty` and `twoHom .four .bool = Empty` (`Textbook.U70.twoHom_cross_empty`), so naturality across arrows connecting distinct presentations with different carriers is not exercised and remains `OPEN`. Similarly, the change-log phrase "across presentations" applies to the transport definitions (`PresIso`, `mapPair`), whereas the obstruction theorems act on automorphisms of one presentation (`Hom a a`).
- **Near-definitional status of `no_natural_section_of_fixed_point_free`**: Over `autoFamily O F`, `IsNatural` unfolds to `F.mapPair (s ()) = s ()`. As `Textbook.U70.natural_section_iff_fixed_pair` confirms, existence of a natural section over `autoFamily O F` is equivalent to existence of an admissible pair fixed by `F.mapPair`.
- **No derivation of `ContactKernel.no_equivariant_pair_valued_map`**: `bool_obstruction_and_sealed_selector` is a conjunction of three already-proved theorems (`negIso_fixed_point_free`, `no_natural_section_boolEq`, and `no_equivariant_pair_valued_map`). Reducing the sealed total-selector theorem on `DiffObs Bool Bool → Bool × Bool` to `no_natural_section_of_fixed_point_free` is explicitly `OPEN`.
- **No categorical closure, no general `Family → HFamily` embedding, and unused `Viable`**: Neither `Family` nor `HFamily` assumes identity arrows, composition, or inverses (`Hom a b` is a declared index type, not a category hom-set); `hAuto_iff_auto` bridges `Family` and `HFamily` only at one object (`Unit`); and the structure `Viable` (lines 196–198) is never referenced after its definition.

## Outside the system

- **`PresIso` and `Family`/`HFamily` are declared notions**: Which carrier and residual bijections count as presentation isomorphisms (`PresIso`) and which arrows are included in a family (`Family`, `HFamily`) are modelling declarations, not derived inside the system.
- **Metatheoretic dependent function types**: `Sec D := ∀ a : D.Obj, NonZeroPair (D.obs a)` and `HSec D` are Lean dependent function types (`Π`-types) over `Type`-level index types `Obj`, `Arr`, and `Hom a b`.
- **Axiom budget**: 29 of the 30 theorems in `PresentationNaturality.lean` are completely axiom-free (`does not depend on any axioms`), because `Bij` carries its inverse as data and all finite checks discharge by `decide` or `rfl`. The single theorem that uses an axiom is `bool_obstruction_and_sealed_selector`, which inherits `[Quot.sound]` from `ContactKernel.no_equivariant_pair_valued_map` (`swapObs_boolEqObs`'s `funext`).

## Student exercise

On `card4Obs` (`Card4 = {e1, e2, e3, e4}` with equality as zero relation), `twIso` swaps `e1 ↔ e2` and fixes `e3` and `e4`. Using `Textbook.U70.twIso_moves_e1_e2` and `Textbook.U70.twIso_fixes_card4PairSwap`, list all admissible pairs `p : NonZeroPair card4Obs` that are fixed by `twIso.mapPair`, and explain why `fun _ => card4MovedPair` is a valid raw section in `Sec (autoFamily card4Obs twIso)` that fails `IsNatural`.

## Answer

An admissible pair `(x, y)` of `card4Obs` satisfies `x ≠ y` (there are $4 \times 3 = 12$ such pairs). For `twIso.mapPair` to fix `(x, y)`, we need `(tw x, tw y) = (x, y)`, meaning both `x` and `y` must be fixed points of `tw`. Since `tw` moves `e1` and `e2` (`tw e1 = e2`, `tw e2 = e1`) and fixes only `e3` and `e4`, the only off-diagonal pairs fixed by `twIso.mapPair` are `card4Pair = (e3, e4)` (`twIso_fixes_card4Pair`) and its transpose `card4PairSwap = (e4, e3)` (`Textbook.U70.twIso_fixes_card4PairSwap`). The constant section `fun _ => card4MovedPair` at `(e1, e2)` is a well-typed raw section in `Sec (autoFamily card4Obs twIso)` because `e1 ≠ e2`, but `twIso.mapPair card4MovedPair = (e2, e1) ≠ (e1, e2)` (`Textbook.U70.twIso_moves_e1_e2`), so it fails `IsNatural`.
