# Search lab: what must we add to tell two entries apart?

Start with two entries and no questions that distinguish them. You are
asked to make a distinction available. What could you add? What would
count as the cheapest repair? What evidence would let someone check it?

## The assumptions we carry

We supply an admission grammar, a list of entries, a separation demand,
two price rules, and finite search bounds. None is generated merely by
looking at the printed seed mark. The calculations concern those declared
choices. An application to a real device needs measurements and its own
tested correspondence.

AuthorityEffect: None. This is explanatory apparatus outside the sealed
derivation. The kernel is consumed read-only. Learning outcomes and
reading time still require novice testing.
