# 00. A ledger and a demand

[Search lab](README.md) · [Next: a form and an instance](01_form_and_instance.md)

## Predict

A **ledger** is a record of what has been admitted and which requirements
have been imposed. Ours has two admitted entries, which we call A and B.
It has no forms for making judgments and no recorded instances of them.

We now write: **A and B must be distinguishable.** Has a distinguishing
test appeared just because we recorded that requirement?

## A request is a different entry from its answer

A **separation demand** says that an available test must succeed on one
of the named entries and fail on the other. Recording the demand changes
the list of requirements. It does not create the test that meets it.

| Part of the ledger | Before the demand | After the demand |
|---|---|---|
| Admitted entries | A, B | A, B |
| Forms and recorded instances | None | None |
| Required separations | None | A from B |
| A witnessed separation | None | Still none |

The demand is now **unmet**. It states a task for a proposed change.
It is not a prediction that the task has already succeeded.
