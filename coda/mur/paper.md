# The Move

**Author:** Jeremy H. Carroll

**Status:** draft bind of the transport layer. Unfinished on
purpose. No version, no release, no hashes.

**AuthorityEffect:** `None`

---

## What this page is

Writings move. Compiling, coarsening, translating, forgetting,
relocating a packet, making soup, tying shoes, having a nightmare:
each is a change of presentation. This layer asks whether the
**move** is honest. It does not ask whether the leftover is small.
It does not grant standing in the target.

The published general-theory paper is a guide. The flypaper and
the stop are already bound. Hilbert lift is a different run.

External frames (read-only): `001_coda/002_coda_mur`; the GenX
transport receipt
`omega_engine_frontier_research/generation_x_transport_receipt.yaml`
(relocation is explicit transport; no path move silently upgrades
proof authority); licence-as-permission paper `046` as a later
kind, not this page.

## 1. One sentence

A change of writing does not keep standing. A move needs a check
that the target's descent data matches the image of the source's,
an explicit list of what was dropped, and an actual stop in the
target. A certificate of the move is not enough.

---

## 2. Track A — what can be attached

Say a map `F` takes a writing in regime A to a writing in regime
B.

- **Match.** Whatever descent record B will use on `F(x)` must
  be the image of the record A used on `x`, or the mismatch is
  named. The published name for that match is a 2-cell
  `chi_F`. Treat the symbol as a label, not a new world.
- **Loss list.** If `F` forgets magnitude, phase, a file, a
  joke, a constraint, write it down. Two moves paste their
  lists.
- **Stop in B.** Even a clean match plus a complete loss list
  does not inhabit standing in B. The stop layer still has to
  run in B.

Worked archive example: the GenX receipt moved frontier packets
from one folder to another. It recorded old path, new path, a
tree digest, and `PATH_ONLY`. Historical evidence stayed
immutable. That is transport as bookkeeping. The digest is not
a theorem and not a grant.

Soup, shoes, nightmares belong here as **the same shape**, not
as extra metaphysics: each is a rewrite with something dropped
and something kept. If you cannot name the drop, you are
laundering.

---

## 3. Kill

- A prettier writing is not the same object and not a better
  standing.
- A valid move certificate without a target stop is not
  standing.
- A path change that "just is" the same proof is a silent
  upgrade. The GenX invariants refuse that.
- Hilbert clothing of leftover mass is a lift (other prompt),
  not a transport certificate.
- Continuum talk that "obviously" carries finite standing is
  a window problem, not a free move.

## 5. Falsify

This bind fails if a lossy quotient is said to keep standing
without a loss list, or if a match certificate alone is called
a grant, or if a folder move is called a new theorem.

## 6. Does not authorize

The stop still applies. This page does not authorize its own
moves.
