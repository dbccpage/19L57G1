# CODA

The canon. New papers are written here.

## Rules for this directory

Distinct from the sealed derivation (`prompt/`, `paper/`, `code/`,
`lean4/Derivation/`, `artifacts/`), which stays blind and is not amended.

- **External citation is permitted.** Prior art may be named, situated, and
  argued against. The blind protocol does not apply here and never did —
  it governs the derivation only.
- **What actually inspects this directory: one thing.** The vocabulary
  firewall in `tests/test_primitive_contact.py` walks the whole tracked
  tree, so the 102 working-denylist identifiers are barred here as
  everywhere. It is a test, not one of the eight gate families.

  **None of the eight gate families reads `coda/`.** Prompt hashes read
  `prompt/`; transport citations read one fixed file under `contact/`;
  coverage and mypy are scoped to `code/`; artifact regeneration runs
  `code/run_*.py`; the Lean job reads `lean4/`; the skills gate reads
  `.claude/skills/`; the citation gate reads `paper/`. An earlier version
  of this file said "all eight gate families apply, unchanged" — that was
  **false** and is WITHDRAWN. Nothing here is gate-protected beyond the
  firewall, and prose in this directory should be read accordingly.
- **Claim typing carries over** — see the assumption discipline in
  `CLAUDE.md`, which is the single source for the type vocabulary and for
  the restricted words. Do not restate the list here. An earlier version of
  this file restated it and the copy already diverged: it dropped five
  types, added one, and dropped two restricted words.
- **Withdrawal in place.** When a claim narrows, quote the withdrawn
  wording rather than replacing it silently.

## The derivation is evidence, not a predecessor

The sealed derivation is a blind case study for the CODA argument: a system
that generated no demands of its own, whose minimum responses were provably
multivalued, and where the obvious deterministic selection rule was rejected
for depending on presentation. It was carried out without knowledge of what
it would be used to argue, which is precisely what makes it usable as
evidence. Cite it; do not revise it.
