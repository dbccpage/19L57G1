# 19L57G1 research run -- priced admissions, not a story

Run this as one autonomous construction workflow on merged `main`
plus the current thinghood packet if it is already on the branch.

This is not a summary of sealed papers.  It is not a cosmogony.
It is not permission to mint time, observers, angels, or a next
universe.  It is a construction run that must either produce
priced, replayable objects, or stop at a named open.

Continue until each goal below has a receipt line, a falsifier,
and an evidence class, or a smallest named obstruction remains.
Do not stop after restating an existing theorem.

Do not ask the user questions.  Do not wait for guidance.
Do not target a predetermined survivor.

AuthorityEffect: None.

---

## 0. Why this run exists

The sealed record already answers "what is Primitive Difference?"
The thinghood packet already answers, inside one declared grammar,
"what is the cheapest object for which collapse can fail a law?"

Neither record answers:

- whether a collision, a pair of equal profiles, or a residual
  is already a well-formed next challenge in the *existing*
  event grammar;
- whether orientation is an independent admission;
- whether the companion inscription plus Supply can purchase
  a thing without further declaration.

Those are the only goals.  If they cannot be answered, name the
missing admission and stop.  Do not invent a clock to fill the gap.

## 2. Evidence classes

Every substantive line uses exactly one of:

    SUPPLIED_INPUT
    DEFINITION
    DECLARED_POLICY
    CONDITIONAL_THEOREM
    FINITE_COMPUTATION
    COUNTERMODEL
    OPEN
    REFUSED

A lookup table that classifies missing flags is DECLARED_POLICY.
It is not FINITE_COMPUTATION.  If you write a table, label it
as a table.  A computation must construct the objects it judges.

The words forced, minimal, free, canonical, equivalent, universal,
complete, and endogenous appear only with a proof or a precise
conditional scope.

## 3. House rule

Nothing happens that is not declared.

If a construction needs a carrier, a pair, a relation, a witness,
a law, an orientation, a store, an observer, a comparison, a
closure policy, a budget, or a license, write it on the bill.
If you cannot point to the declaration, the object does not exist
in this run.

Choice is not a theorem.  Choice is the leftover after the bill
and the measure are written.  Do not hide leftover under a slogan.

## 4. Goals, in order

Execute these steps.  A later step may not assume a unique
survivor from an earlier step that still has a tie.

1. State the write root, the sealed paths you will not touch,
   and the receipt schema.  Hash this prompt.  Stop if the hash
   drifts during the run.

2. Import nothing from sealed implementation into the object
   language of this tree.  You may *cite* sealed names as
   CONDITIONAL_THEOREM.  You may *reuse types and functions*
   only by reading them and reconstructing the needed fragment
   here, with the reconstruction labeled METATHEORY.

3. Build three concrete objects, each from ingredients the
   repository already has names for:
     (a) one collision (identified endpoints of an asserted pair);
     (b) one case of equal profiles;
     (c) one directional residual of two presentations.
   Each object must be inspectable: carrier, edges, maps, and
   what is *not* present.  Do not encode them as flag records.

4. For each of the three objects, search the *existing* event
   grammar (Admit / Supply / Impose / Observe / the sealed
   challenge and response constructors) for a well-formed next
   event whose extra ingredients are already inside that object.
   Report found or not-found.  If not-found, list the missing
   admissions.  Do not add a demand-source field to the
   definition of "next event" and then celebrate its absence.

5. Declare whether orientation is an ingredient of this run.
   If you include it, give it its own bill atom and an iso key
   that does not forget the ordered pair.  If you exclude it,
   say so as DECLARED_POLICY.  Either way is legal.  Silent
   forgetting of D2 / S2 is not.

6. Re-run the thinghood minimum only if step 5 added or priced
   orientation, or if you change the cost measure.  Use one
   named measure.  Retain every tied non-isomorphic class.
   Do not select a unique delta.

7. Write the six S9 admissions as bill lines: carrier, two
   occurrences, relation, witness, irreflexivity, orientation.
   Starting from the inscription plus Supply only, report
   which lines are paid and which are not.  Do not elaborate
   the inscription into a witnessed irreflexive datum.

8. If you enlarge the law list, keep the enlargement finite and
   named.  For each added law, report whether identifying a
   witnessed pair can violate that law.  Uncompared laws stay
   OPEN.  Do not treat absence of a search as uniqueness.

9. Keep three words distinct: datum, difference, thing.
   Do not rename Primitive Difference as thing.  Do not treat
   a local A1i skeleton as the sealed D2 / S2 pair.

10. Keep three opens open: S6 item 6, S9 last bullet, OB-1.
    Negative tests must fail the run if any of those are
    claimed closed.  A narrower open is legal.  A closure is not.

11. `two_rule` remains a menu at an already active obstruction.
    Do not fire it at genesis.  Do not call it a law of the
    inscription.  Do not call demand persistence a repair.

12. generation_never_dries, if cited, stays scoped to declared
    stepRefl plus declared pair-separation closure plus n >= 3.
    That is demand, not genesis, not time, not a world.

13. Every count without a min-response or collapse-witness is
    not a claim.  Withdrawals remain withdrawals.

14. Write CLAIM_LEDGER.md with stable IDs, evidence class,
    evidence pointer, and falsifier.  Write a timestamp-free
    JSON receipt.  Update STATUS.md with terminals and scope.

15. Run deterministic tests, including negatives for the
    forbidden closures and for "table claimed as computation."
    Receipt must replay byte-identically.

16. Stop.  Do not add a seventeenth object that "makes the
    universe go."  If leftover remains, name it leftover.

  relative to a protected law.

- FW-OB1 -- do not close OB-1, S6.6, or S9 last bullet.
- FW-TIES -- retain ties unless uniqueness is proved.
- FW-BILL -- stores, observers, budget, license, orientation
  if used, are not free.

- FW-IMPORT -- no time, no cosmology, no external theory,
  no silent sequence-of-simplexes.
- FW-NAME -- do not identify thing with Primitive Difference
  by slogan.

  the winning tick, or the winning orientation price.
