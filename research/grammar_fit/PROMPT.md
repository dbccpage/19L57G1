# 19L57G1 research run -- fit objects to the grammar, or name the gap

Run on merged main plus the current priced-admissions packet as read-only
input.  Write only under research/grammar_fit/.

This run does not mint time, observers, cosmology, or a successor of the
world.  It asks whether the three priced objects can be seated in the
reconstructed event grammar without adding undeclared ingredients, and
whether any remaining leftover is a missing admission or a missing
constructor.

Do not target a predetermined survivor.  Do not close OB-1, S6.6, or
S9 last bullet.  Do not cite the thinghood tick_analysis table as evidence.

AuthorityEffect: None.

House rule: nothing happens that is not declared.  A label attached to a
field is not a state change unless the constructor mutates the state.
A table of missing flags is DECLARED_POLICY, not FINITE_COMPUTATION.

---

Execute in order.  A later step may not assume a unique survivor from
an earlier step that still has a tie.

1. Hash this prompt.  State write root and sealed paths.  Stop on drift.

2. Reconstruct only the constructors you use.  Label the reconstruction
   METATHEORY.  Do not import sealed implementation into object language.

3. Seat the collision object in a grammar state.  Either the asserted pair
   and identifying map become fields of that state by named constructors,
   or they remain outside and you say so.  Do not smuggle them.

4. Seat the equal-profile object in a grammar state the same way.

5. Seat the residual object in a grammar state the same way.

6. For each seated state, list constructors that fire using only fields
   already present.  Separate columns:
     object-derived state change
     object-derived no-op label
     external challenge
     guarded response
   A no-op must not set NEXT_EVENT_FOUND.

7. Build one non-trivial equal-profile case: same form, an instance or
   rule that holds of one datum and not the other, or report that the
   declared form/instance grammar cannot produce that case.  Do not
   treat empty=empty as the only case unless you prove it is.

8. Price comparison policy as its own bill line, or exclude it as
   DECLARED_POLICY.  If priced, say what constructor spends that atom.
   If excluded, the residual leftover stays named.

9. Write one named cost measure.  If you keep both the thinghood measure
   and the oriented-S9 measure, exhibit one candidate whose rank changes
   across them, or prove the ranks agree on the declared space.

10. Keep orientation as an explicit atom if you use ordered pairs.
    Iso keys must not forget the ordered pair.  Retain ties.

11. If you enlarge the law list, keep it finite and named.  For each
    added law, report whether identifying a witnessed pair can violate
    it.  Uncompared laws stay OPEN.

12. Replay inscription plus Supply only against the S9 six lines again
    after any grammar seating.  Do not treat Supply as admission.

13. Keep datum, difference, and thing distinct.  Do not rename
    Primitive Difference.

14. Keep OB-1, S6.6, and S9 last bullet open.  Negative tests fail
    the run if any is claimed closed.

15. two_rule stays a menu at an already active obstruction.
    generation_never_dries, if cited, stays scoped to declared
    stepRefl, declared pair-separation closure, and n >= 3.

16. Every count without a collapse-witness or a min-response is not
    a claim.  Withdrawals remain withdrawals.

17. Write CLAIM_LEDGER.md, a timestamp-free receipt, and STATUS.md.
    Receipt replays byte-identically.

18. Tests must include: object seating, no-op vs state-change split,
    non-trivial profile case or a named impossibility, comparison
    policy priced or excluded, forbidden closures, table-as-computation
    refused.  No pytest import required.

19. Do not write sealed paths.  Do not amend sibling receipts.

20. Stop.  Name leftover.  Do not add a clock.
