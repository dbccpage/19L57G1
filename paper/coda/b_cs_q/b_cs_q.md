# b_cs_q

**[declared metatheory]** Reference (read-only, not imported):
`005_coda_cs_q_bridge.md`. This page is a skeleton of the subject.
Nothing here is a theorem, a receipt, or an admitted claim.

This is the gate between finite samples and questions asked as if the
object were continuous.

If a question is really a function of the sample profile, then anything
that shares a profile gets the same answer. On the image of the profile
map, the converse holds: constant-on-fibers means there is a well-defined
factor through the samples. A reverse that works for every possible
input, with no extra section or choice, is not given here.

The admission steps that let a question through are a list of
obligations. They are not a proof that the continuum exists, and they
are not standing for the whole object.
