# gtla

**[declared metatheory]** Reference (read-only, not imported):
`007_gtla.md`. This page is a skeleton of the subject. Nothing here is
a theorem, a receipt, or an admitted claim.

Inside one declared system, moving evidence around does not create
standing.

Standing is a license, under a named regime and a named kind, to treat
something as granted. Authorization is the process that tries to earn
that license. They are not the same thing. A successful check, a
routing decision, a leftover size, and a license are four different
kinds of value; none of them coerces into another.

Steps that create no standing still create none when composed.
Obligations add; they are not quietly erased. Promotion, when it
happens, is a separate certificate, not an output of the ordinary
moves. A missing filler in one system is not a theorem that no filler
exists anywhere.
