This reserved page is not that bind. External frame (read-only, not
imported): `001_coda_fda.md`.

Having a candidate is not the same as having standing to treat it as
granted. Standing, when it exists, is a finite record: what is being
judged, who evaluates, who checks, where the check is allowed to stop,
and under which rules. The record must actually reach that stop.

A score, a fluent answer, or a high confidence value does not create
standing. If the record is missing, the answer is a refusal, not a
silent pass. If the check ends in a refusal, standing is empty.

Not every true statement is required to have such a record. This layer
does not invent standing. It only says when a candidate is allowed to
count as granted inside a declared finite system.
