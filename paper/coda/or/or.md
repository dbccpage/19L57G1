# or

**[declared metatheory]** Reference (read-only, not imported):
`003_coda_or.md`. This page is a skeleton of the subject. Nothing here
is a theorem, a receipt, or an admitted claim.

Several evaluations can be placed side by side: a product, a limit, a
vote, a consensus object. That organizes comparison. It does not raise
the standing of the combination above the standing of the parts.

If no part has standing, the combination has none. An empty list of
supporting parts is a refusal, not a new source of standing.

Disagreement is written down as a leftover. It is not averaged into a
verdict it did not earn. Combining views does not invent a view from
nowhere, and it does not settle which view is right.
