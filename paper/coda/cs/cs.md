# cs

**[declared metatheory]** Reference (read-only, not imported):
`004_coda_cs.md`. This page is a skeleton of the subject. Nothing here
is a theorem, a receipt, or an admitted claim.

Talk about a continuous or infinite object is allowed only for a
question that factors through a finite sample of that object. If two
objects look the same in every admitted sample, the question must give
the same answer on both.

Writing a limit symbol, or saying a tower is coherent, does not build
the infinite object and does not grant standing for every question about
it. Standing, when it exists, is relative to the question, not to the
whole object.

Agreement on samples is not identity of the objects. This layer does
not construct the continuum from nothing.
